# Chat Cat 使用指南（v1.0）

面向第一次使用的完整流程：装上 → 接入 → 对话 → 把历史搬过来 → 日常维护。
预计 10 分钟可以全部走完。

---

## 1. 安装

**方式 A：直接装 APK**

1. 下载 `chatdemo-v1.0.0-release.apk`
2. 手机上点击安装，如提示「未知来源」，在系统设置里允许本次安装
3. 桌面出现橙色小狮子图标「Chat Cat」

**方式 B：从源码构建**

```bash
# 需要 JDK 17 + Android SDK 36
./gradlew :app:assembleDebug     # 调试包
./gradlew :app:assembleRelease   # 正式包（需 keystore.properties，见 docs/11）
```

系统要求：Android 8.0 及以上。

---

## 2. 首次接入：充值 → 创建 Key → 粘贴

应用不会强制你登录，也不会代管账号。你只需要一个自己的 API Key。

### 第 1 步：充值

打开应用任意入口进入「接入 API」页（无 Key 时点提示条，或 设置 → 账号管理 → 更换 API Key），点 **「去充值」**。

浏览器会打开 DeepSeek 开放平台充值页，用手机号/邮箱登录后充值。建议先充小额（例如 10 元）试用，API 是按 token 计费的。

### 第 2 步：创建 API Key

回到应用，点 **「创建 API Key」**，进入开放平台「API keys」页面：

1. 点「创建 API Key」
2. 名称随便填（例如 `chat-cat`）
3. 创建后点**复制**（Key 形如 `sk-xxxxxxxxxxxxxxxx`，只显示一次，请自己另存一份）

### 第 3 步：回到 Chat Cat 粘贴

从浏览器切回 Chat Cat 时，应用会自动读取剪贴板：

- 检测到 `sk-` 开头的 Key → 弹窗「检测到剪贴板中的 API Key」，点 **填入**
- 只显示首尾几位（如 `sk-abc…wxyz`），不会把整串铺在屏幕上

也可以手动处理：

- 点输入框右侧 **「粘贴」**
- 或直接长按输入框粘贴

填入后点 **「验证并开始」**，通过校验即进入对话页。Key 会以密文保存在本机（Android Keystore）。

> 费用提示：所有请求都记在你自己的开放平台账户上。Chat Cat 不经手支付，也不抽取任何费用。

---

## 3. 开始对话

| 想做的事 | 怎么做 |
| --- | --- |
| 新对话 | 侧边栏「新建对话」；已经在空白对话里时只会提示，不会重复建 |
| 深度思考 | 输入框上方「深度思考」开关，新对话默认开启（可在 设置 → 个性化 改） |
| 联网搜索 | 输入框上方「智能搜索」开关；回答里的角标可点开来源 |
| 发文件 | 点「+」选 PDF/Word/PPT/图片；选中即上传，带进度，失败可重试 |
| 换模型 | 顶部模型名切换 V4.1 Flash / V4 Pro（会提示成本差异） |
| 停止生成 | 生成中点停止；停止后可点「继续生成」接着写 |
| 重新生成 | 回答下方「重新生成」，旧答案保留，用 `‹ 2/3 ›` 切回 |
| 改提问 | 长按自己的消息 → 修改，旧分支保留 |
| 复制/分享 | 长按消息；表格可「复制为 CSV」 |

## 4. 把历史对话搬过来

入口：**设置 → 数据管理**。

### 4.1 默认模式：从 DeepSeek 全量导入历史数据

官方导出入口在**网页版**（`chat.deepseek.com` → 设置 → 数据管理 → 导出所有历史对话）；
App 内若没有该入口，直接用网页版即可。

1. 在「数据管理」点 **「从 DeepSeek 全量导入历史数据」**
2. 点 **「打开网页版 chat.deepseek.com」**（或「打开 DeepSeek App」，未安装时置灰）
3. 在官方侧依次点：
   **设置 → 数据管理 → 导出所有历史对话**
   等它生成完成后，点 **获取下载链接** 并 **复制**
4. 返回 Chat Cat（按返回键或从最近任务切回）
5. 应用会自动读取剪贴板（回到前台会重试多次），识别到导出链接后弹窗：

   > 检测到导出下载链接
   > 是否下载该导出包？下载完成后会先显示备份内容，再由你选择合并增量或覆盖导入。
   > [下载并导入] [暂不]

6. 点 **下载并导入**，界面显示「正在下载 xx%」，下载完自动进入 **导入确认页**：
   显示备份格式、对话数、消息数，并让你选择导入方式（见 4.3）
7. 选好方式点 **开始合并** / **覆盖导入**，完成后引导页显示结果（如「已合并 3 个新对话、42 条消息，跳过 122 个已存在」），
   点 **完成** 收起

没自动弹窗？三种兜底：

- 点 **「我已复制链接，立即检测」** 再试一次；面板上会显示「剪贴板读到：…」帮你确认复制到了什么
- 在 **「或手动粘贴下载链接」** 输入框里长按粘贴，再点 **「用此链接导入」**（系统禁止读剪贴板时用这条）
- 点 **「粘贴剪贴板内容」** 把剪贴板原文填进输入框再导入

> 官方导出包托管在对象存储上（如 `*.obs.cn-*.myhuaweicloud.com`），域名不是 `deepseek.com` 属于正常情况。
> 应用按「像不像一个可下载的导出文件」判断，确认弹窗会标出主机与文件名，可信托管域不会报警告。

### 4.2 降级模式：手动上传 ZIP

以下任一情况，请走这条路径（入口同样在引导页底部或数据管理页）：

- 系统不给读剪贴板（部分定制系统、或应用不在前台），且手动粘贴也不方便
- 剪贴板里没有链接 / 复制成了普通对话页地址
- 链接已过期、下载中断
- 导出包超过 512 MB

步骤：

1. 点 **「无法自动导入？上传 ZIP 文件」**
2. 在文件选择器里找到 `deepseek_data-xxxx.zip`（通常在「下载」目录）
3. 应用解析后显示备份格式、对话数量、消息数量
4. 选择导入方式：**合并增量（推荐）** 或 **覆盖本机对话**
5. 如备份里有可识别用户名，可选择是否保留显示名（只存显示名，不读邮箱/手机号）
6. 点 **「开始合并」** 或 **「覆盖导入」**

### 4.3 导入前必读

- **两种导入方式**（确认页可选，默认合并）：
  - **合并增量（推荐）**：保留本机现有对话，只把备份里有、本机没有的会话加进来。按「标题 + 创建时间」
    判断是否已存在，同一份备份重复导入不会产生副本；本机改动过的同名会话不会被覆盖。
  - **覆盖本机对话**：清空本机全部对话后整体替换，无法撤销，执行前建议先「导出所有历史对话」。
- **只导入当前分支**：官方消息树里被「修改提问」隐藏的旧分支不会导入。
- **附件只有元信息**：官方 ZIP 不含附件二进制，导入后能看到文件名/大小/类型，但打不开原文件。
- **失败不动原数据**：整个包解析成功后才在单个事务里落库；解析失败时本机数据保持不变。

## 4.4 思考链与公式

- **思考链展示**（设置 → 个性化）三档：「限高展开」为默认——思考时展开一块限高区域，思考内容在其中流式滚动，
  结束后自动收起；「默认收起」只看「已思考（用时 N 秒）」；「展开全部」始终展开，与正文一起自然滚动。
  手动点开/收起过的回答，不会再自动折叠。
- **公式**：回答里的 `$$...$$` 或 `\[...\]` 会排版成带分式/根号/上下标的公式；行内 `$x^2$` 显示为 `x²`。
  公式过宽时可以左右拖动。
- **正文保护**：正文默认不可选中（也不会误触拖动选择）；需要复制时，长按消息 →「选择文本」。
  正文里的链接可以直接点开，在应用内浏览器里看，不跳出应用。
- **搜索结果**：思维链里的「搜索到 N 个网页」、回答末尾的「N 个网页」都是胶囊按钮，点开是搜索结果页；
  点任意一条进应用内浏览器，右上角还可以「用外部浏览器打开」。
- 正文里的角标 ¹ ² ³ 对应当轮搜索到的网页，点一下直接打开该来源。

## 4.5 充值

- 余额页小狮子下方有「给橘狮充饭卡」，点一下直达开放平台充值页
- 余额低于预警线时，小狮子会变成「没余粮」表情，点小狮子本身也能去充值

## 4.6 协议与合规

- 首次填写 API Key 前需要阅读并勾选同意《Chat Cat 用户协议》《DeepSeek 用户协议》《DeepSeek 开放平台服务协议》，
  三者一次性确认；服务协议页也提供这三份协议的入口。
- 应用默认开启官方内容安全审核参数，命中风险时请求会被拒绝或回答被拒答，费用按开放平台规则计费。
- 严禁利用本应用生成、传播违反法律法规的内容。

## 5. 余额与用量

- **左下角余额**：对话页输入框下方左侧常显「余额 ¥x.xx」，点一下进余额页。低于预警线时变红加粗。
  刷新时机有两个：每次回答结束后、以及每 5 分钟一次的低频同步。
- **余额页**：设置 → 账户 → 查询余额。显示总余额 / 充值余额 / 赠金余额；余额不足时可直接点「去开放平台充值」。
- **预警线**：余额页的「余额预警线」滑块（¥1–200，默认 ¥10）。低于该值时聊天页余额转提示色，
  余额页底部也会换成「没余粮」的小狮子。
- **单条用量**：回答下方的「用量」，可看本次输入/输出 token 与估算费用。
- **本月累计**：设置 → 账户 → 用量统计。

估算值按模型单价计算，仅作参考，实际扣费以开放平台账单为准。

### 5.1 防伪校验

设置 → 关于 →「应用签名校验」可随时检查当前安装包是否为官方签名。导入历史数据、充值、填写 API Key
这类敏感操作前，应用也会自动校验；签名不一致会直接拦下并提示前往 GitHub / Gitee 获取正版。

### 5.1 多个 API Key 怎么管

设置 → 账号管理 → **管理 API 密钥**：

- 点 **添加 API Key**，可填一个名字（如「工作号」「个人号」），Key 可用「粘贴」从剪贴板读取
- 列表里当前使用的那条带 **使用中** 标记；点其它条目即切换，立即生效，不用重新输入
- 行尾 ⋮ 可 **重命名** 或 **删除**（只删本机记录，不影响开放平台上的 Key）
- 列表只显示 `sk-ab…7890` 这样的掩码，应用不提供明文查看或导出

> v1.0.1 及更早版本的「更换 API Key」会先清空当前 Key 再打开配置页，中途返回就丢了配置；
> 本版改成账户列表，切换不再触碰其它 Key。

## 6. 备份、迁移与删除

| 需求 | 操作 |
| --- | --- |
| 备份到本地 | 设置 → 数据管理 → 导出所有历史对话，选保存位置 |
| 换手机迁移 | 旧机导出 ZIP → 传到新机 → 新机「上传 ZIP 文件」导入 |
| 只清空对话 | 设置 → 数据管理 → 删除所有历史对话（Key 与设置保留） |
| 清除 Key | 设置 → 清除 API Key（对话不删） |
| 彻底卸载 | 直接卸载应用；本机数据库与 Key 一并删除，云端无副本 |

导出的 ZIP 是官方 v3 格式，也可以在 DeepSeek 官方网页端导入。

## 7. 常见问题

**Q：提示「API Key 无效」？**
A：确认复制完整（`sk-` 开头，没有多余空格）；确认 Key 未被删除或禁用；如使用第三方中转地址，到 设置 → 高级设置 检查 API 地址是否正确。

**Q：提示余额不足 / 请求被拒？**
A：到 设置 → 查询余额 看是否可用，余额为 0 时点「去开放平台充值」。赠金与充值余额是分开显示的。

**Q：回到应用没有弹「检测到导出下载链接」？**
A：1）确认复制的是「获取下载链接」给出的链接，而不是官方页面地址；2）回到应用后稍等 1–2 秒，应用会在 350/700/1200/2000 ms 各重试一次读剪贴板；3）看引导页上的「剪贴板读到：…」提示，确认复制的内容到底是什么；4）系统拒绝读取剪贴板时，用「或手动粘贴下载链接」输入框粘贴后点「用此链接导入」；5）仍不行就走「上传 ZIP 文件」，效果完全一样。

**Q：提示「下载链接已失效」？**
A：导出链接有时效，回官方 App 重新执行一次导出，拿到新链接再回来。

**Q：导入后对话数量比官方 App 里少？**
A：只导入每个会话的**当前分支**；被「修改提问」隐藏的历史分支不会导入，这是与官方导出语义一致的行为。

**Q：导入会不会把我现在的对话覆盖掉？**
A：默认不会。导入确认页默认选「合并增量」，本机现有对话原样保留，只补备份里新增的；
只有你显式选「覆盖本机对话」才会清空后整体替换。

**Q：导入后图片/文件打不开？**
A：官方导出包不含附件二进制，只保留元信息。原文件需要回到官方 App 查看或重新上传。

**Q：为什么不能直接读官方 App 的聊天数据库？**
A：Android 应用数据相互隔离，官方也未提供本地读取接口。当前方案走的是官方自己提供的「导出历史」能力，不需要 Root，也不违反平台规则。

**Q：应用会把我的对话上传到别处吗？**
A：不会。应用不运营服务器；对话只存本机，发送消息时直接请求你配置的 DeepSeek API 地址。详见 设置 → 隐私政策。

**Q：会收集统计数据吗？**
A：不收集。没有埋点、没有账号体系、没有远程配置。
