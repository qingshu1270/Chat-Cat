# Chat Cat 功能介绍（v1.0）

> 一个用 DeepSeek 开放平台 API 驱动的第三方 Android 客户端。
> 目标很具体：把 DeepSeek 官方 App 的对话体验原样搬到「按量付费的 API」上，再把最难的两件事——**接入**和**搬家**——压缩成几步。

- 版本：v1.0.0（2026-11-19）
- 平台：Android 8.0+（minSdk 26，targetSdk 36）
- 许可：GNU General Public License v3.0
- 与官方关系：第三方客户端，与 DeepSeek 官方无隶属关系

## 1. 为什么做这个

官方 App 的免费额度有上限，超出后官方开放平台提供 API 按量计费。但直接拿 API 用，会立刻撞上三道墙：

1. **要自己准备 Key**：注册开放平台、充值、创建 Key、填进客户端，一步劝退很多人。
2. **历史对话带不走**：几百个会话留在官方账号里，新客户端从零开始。
3. **体验断崖**：官方 App 的思考过程、搜索步骤、版本切换、引用角标，普通 API 客户端一个都没有。

Chat Cat 1.0 针对这三点分别给出：**三步接入**、**双模式全量导入**、**对齐官方 App 的对话交互**。

## 2. 核心能力

### 2.1 对话

| 能力 | 说明 |
| --- | --- |
| 流式输出 | SSE 全事件解析，50 ms 合并刷新；随时停止，停止后可「继续生成」 |
| 深度思考 | 展示完整思维链，可展开/折叠；结束后折叠为「已思考（用时 N 秒）」 |
| 智能搜索 | 搜索与打开网页步骤可见，可查看来源列表；回答带引用角标 |
| 附件 | PDF / Word / PPT 走版面解析，图片先压缩再上传；带进度、失败可重试 |
| 图片 | 缩略图 + 全屏手势缩放；不支持图片的模型会在发送前拦截 |
| Markdown | 标题、列表、引用、表格（横滚 + 复制为 CSV）、代码块语法高亮与一键复制 |
| LaTeX | 块级公式真排版（分式/根号/上下标/求和积分/希腊字母），行内公式转 Unicode 近似；超宽横向滚动 |
| 代码块 | 多色语法高亮：关键字/字符串/注释/数字/类型/函数各一色，浅色深色各一套 |
| 引用角标 | 按本轮来源顺序 1、2、3… 编号，落在结论后方；模型自带的乱序角标会先重排，行首角标移到行尾 |
| 搜索展示 | 「搜索到 N 个网页」「N 个网页」为胶囊按钮，点开是搜索结果页中页，条目点开进应用内浏览器 |
| 思考链 | 思考内容同样走 Markdown；三档展示：限高流式展开（默认）/ 默认收起 / 展开全部 |
| 合规 | 请求默认开启 `safety_check: high`；首次填 Key 需同意三份协议；输入区与配置页均有禁止违法内容提示 |
| 开关解耦 | 个性化里的思考/搜索开关只影响新对话；会话内开关只作用于当前会话 |
| 正文保护 | 正文默认不可选中（无涟漪、无拖动选中），长按 →「选择文本」后才可选中；正文链接可直接点开（内置 Custom Tabs） |
| 消息操作 | 复制、选择文本、赞/踩、重新生成、修改提问、分享 |
| 回答版本 | 重新生成不覆盖旧答案，`‹ 2/3 ›` 随时切换；修改提问也保留旧分支 |

### 2.2 会话管理

- 侧边栏按「置顶 / 今天 / 昨天 / 7 天内 / 30 天内」分组，支持按标题与预览搜索
- 重命名、置顶、多选批量置顶/删除、单条删除
- **启动即新建对话**：每次进入应用都停在空白对话页（随机小狮子），不自动打开上次的对话；
  历史对话从侧边栏进入
- 新建对话防重复：空白对话不落库，重复点「新建」只提示「已经在新对话中」
- 模型切换带成本提醒（V4.1 Flash / V4 Pro），每个会话独立记忆

### 2.3 接入：从充值到可用，只有三步

API 配置页内置完整路径，不需要自己去翻文档：

```
① 去充值  →  ② 创建 API Key（复制）  →  ③ 回到 Chat Cat（自动识别剪贴板）
```

- 「去充值」「创建 API Key」直接拉起开放平台对应页面
- 从浏览器切回来时自动识别剪贴板中的 `sk-` Key，弹窗询问是否填入（只显示首尾，避免整串暴露）
- 也可以点输入框右侧「粘贴」，或直接手填
- Key 用 Android Keystore 加密保存，只随请求发给你配置的 API 地址

### 2.4 搬家：双模式全量导入（v1.0 重点）

#### 默认模式：从 DeepSeek 全量导入历史数据

链路是「打开官方入口 → 用户导出 → 回来自动接手」，用户只需要在官方侧点几下：

```
Chat Cat：从 DeepSeek 全量导入历史数据
   ↓ 打开网页版 chat.deepseek.com（或链式拉起官方 App）
DeepSeek：设置 → 数据管理 → 导出所有历史对话 → 获取下载链接（复制）
   ↓ 回到 Chat Cat
Chat Cat：读剪贴板 → 识别导出链接 → 弹窗「是否下载并导入」
   ↓ 确认
自动下载 ZIP → 校验 → 导入 → 完成提示（N 个对话 / M 条消息）
```

技术细节（也是安全边界）：

- 链接判定按「是否像可下载的导出文件」：`.zip` / `export` / `download` / CDN 子域 / 对象存储签名参数任命中即可。
  官方导出包托管在对象存储（如华为云 OBS，host 形如 `deepseek-…-prod.obs.cn-east-3.myhuaweicloud.com`），
  bucket 前缀本身含 `deepseek` 属正常现象，v1.1 起不再据此判为钓鱼
- 仍拒绝**注册域**被冒充的链接（`deepseek-chat.cn`、`deepseek.com.evil.com`）；确认弹窗只展示主机与文件名
- 下载前校验 ZIP magic 与体积上限（512 MB），HTML 错误页不会被当备份导入；带浏览器 UA 避免被 CDN WAF 拦成 403
- 下载的 ZIP 只落在应用缓存目录，导入结束（成功或失败）立即删除
- 读剪贴板带重试：进入页面 1 次 + 窗口获得焦点 1 次 + 350/700/1200/2000 ms 四次补读，规避 Android 10+ 的焦点限制
- 同一链接只弹一次确认；识别到链接后卡片内也有「下载并导入该链接」，弹窗被关掉仍可继续
- 全程可见：面板显示「剪贴板读到：…」，失败给出可诊断原因，成功后停留展示导入条数

#### 手动粘贴兜底

引导页内置「或手动粘贴下载链接」输入框：

- 「粘贴剪贴板内容」把剪贴板原文填进输入框（读不到时提示系统未放行，请长按粘贴）
- 「用此链接导入」接受任意 `https://` 链接，直接进入下载确认流程

这条路径不依赖剪贴板权限，是部分定制 ROM 上唯一可行的自动导入方式。

#### 降级模式：手动上传 ZIP

以下情况自动保留引导并切换到手动路径：

- 系统拒绝读取剪贴板（部分 ROM / 未获得焦点）
- 剪贴板里没有可识别的导出链接
- 链接过期、下载中断、链接不是压缩包、导出包超过 512 MB
- 用户一开始就选择「上传 ZIP 文件」

手动路径：选择 `deepseek_data-*.zip` → 预览会话数/消息数 → 选择导入方式 → 确认导入
（可选择是否保留备份里的显示名）。链接链路下载完也进入同一个确认页。

#### 导入语义（重要）

- **两种方式，默认合并**：
  - 合并增量（推荐）：保留本机现有对话，只追加备份里没有的；按「标题 + 创建时间」去重，
    同一份备份重复导入不产生副本
  - 覆盖：清空本机现有对话后整体替换，不可撤销
- 导入前会完整解析整个包，解析失败不动原数据；两种方式都在单事务内落库
- 只导入会话当前分支；被「修改」隐藏的旧分支不导入
- 覆盖前建议先「导出所有历史对话」备份一次

### 2.5 账户与数据

- **多 Key 账户**：可以保存多个 API Key 并命名（工作号 / 个人号），列表标注「使用中」，一点即切换；
  只显示 `sk-ab…7890` 掩码，不提供明文查看与导出。切换不会动到其它 Key。
- **余额常显**：对话页左下角一直显示当前余额，点一下进余额页；低于预警线转提示色。
  双刷新——每次回答结束后同步一次，另有每 5 分钟的低频主动同步。
- **余额预警线**：余额页可自设阈值（¥1–200），低于该值时余额页底部换成「没余粮」小狮子，充足时是「吃鱼」小狮子。
- **余额查询**：官方 `GET /user/balance`，展示总余额 / 充值余额 / 赠金余额；余额不足时提供「去开放平台充值」直达
- **用量统计**：每条回答可看本次 token 用量，设置页可看本月累计与 ¥ 估算（区分模型、缓存命中、峰谷价）
- **导出**：官方 v3 ZIP（`manifest.json` + `chat_sessions/*.json` + 索引），可在官方网页端或本应用导入
- **删除**：删除全部对话为独立确认页，Key 与设置不受影响

### 2.6 外观与系统集成

- 浅色 / 深色 / 跟随系统；字号 0.8–1.5 连续滑块，全局实时生效
- 统一圆角体系（10/14/18/24/30dp）：按钮、卡片、弹窗、输入框不再是直角；消息操作图标 12dp 圆角
- 余额预警线滑条：圆角胶囊轨道 + 渐变填充 + 描边圆滑块，两端标注 ¥1 / ¥200
- 余额页小狮子下方常驻「给橘狮充饭卡」；低于预警线时点小狮子也可直接去充值
- 防盗版：`SignatureGuard` 比对安装包签名，导入/充值/填 Key 前拦截异常包，设置页可自查
- 接收系统分享（文本、图片、文件）与划词提问（选中文字直接带入输入框）
- 免 Key 启动：进应用直接到对话页，无 Key 时只显示一条提示与随机小狮子，点按进入配置

## 3. 与官方 App 的差异

**刻意不做**：

- 不反编译、不二次打包、不调用官方 App 私有接口，不复用其任何资源与代码
- 不内置 Key、不做共享 Key 池
- 不使用 DeepSeek 商标与图标作为产品标识

**已知差异**：

- 无语音通话、无联网搜索以外的工具箱入口
- 仅简体中文
- 会话搜索覆盖标题与预览，尚未做全文检索
- 导入不包含官方云端的附件二进制（只保留文件名、大小、类型等元信息）

## 4. 技术一览

| 层 | 选型 |
| --- | --- |
| UI | Kotlin + Jetpack Compose（Material 3），单 Activity + 二级页导航 |
| 状态 | ViewModel + StateFlow，单向数据流 |
| 存储 | Room（会话/消息/块/附件/用量）+ DataStore（设置）+ EncryptedSharedPreferences（Key） |
| 网络 | OkHttp（SSE 流式）+ kotlinx.serialization |
| 归档 | 官方 v3 ZIP 读写；导入可选合并增量 / 覆盖，单事务落库 |
| 构建 | AGP 8.13 / Kotlin 2.2 / JDK 17，R8 混淆，正式签名发布 |

## 5. 隐私

- 不运营服务器，不收集任何用户数据
- 对话只存在本机；发送消息时按你配置的地址请求 DeepSeek 开放平台
- Key 加密存储，日志只记录错误类型与 `request_id`，不含正文与 Key
- 剪贴板只在导入引导页/API 配置页处于前台时读取，命中目标内容才弹窗，不做后台轮询
